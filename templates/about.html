About

Each contact is a name and a phone number. The same contact object is stored in two places.

  • A doubly linked list keeps contacts in the order you added them, so the list can be read forward or backward.
  • A hash table (a Python dictionary) maps each name to that same contact for an exact lookup.
  • Keyword search walks the list and uses naive substring matching on the name.

Contacts stay in memory while the server is running. The same book is available as a text menu with python menu.py.
